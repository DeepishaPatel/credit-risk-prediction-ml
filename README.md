# 💳 Credit Risk Prediction using Machine Learning

A Machine Learning project to predict whether a customer is a **good or bad credit risk** using classification techniques.

## 📊 Model Used

- Random Forest Classifier  


## 📈 Model Performance

- **Accuracy:** 90.5%  

### Classification Report

| Class | Precision | Recall | F1-Score |
|------|----------|--------|----------|
| Good Credit (0) | 0.96 | 0.93 | 0.94 |
| Bad Credit (1)  | 0.66 | 0.77 | 0.71 |


## 🧠 Problem Statement

The goal is to classify customers based on their creditworthiness to help financial institutions make better lending decisions.

## ⚙️ Techniques Used

- Data Cleaning (handling missing values using forward fill)
- Label Encoding for categorical variables
- Feature Selection
- Train-Test Split
- Random Forest Classification
- Model Evaluation (Accuracy, Confusion Matrix)


## 📊 Visualizations

- Target Distribution Plot  
- Feature Importance Graph  

## 📁 Dataset

- German Credit Dataset (CSV file)

The dataset includes attributes like:
- Age  
- Job  
- Housing  
- Saving Accounts  
- Credit Amount  
- Duration  
- Purpose  

---

## 🔍 Target Variable

- **Risk (0 = Good, 1 = Bad)**  
- Created based on credit amount threshold  

## 🚀 Conclusion

The Random Forest model achieved strong performance with over **90% accuracy** in predicting credit risk.

This system can help financial institutions in:
- Loan approval decisions  
- Risk assessment  
- Reducing financial losses
